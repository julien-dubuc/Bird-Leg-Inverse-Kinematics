# Bird-Leg-Inverse-Kinematics

**Redundant inverse kinematics and joint-axis optimisation for a 4-DoF bird leg model, driven by measured 3D trajectories.**

This repository contains the Python code, data, figures and report of a lab assignment for the *Bio-inspired Robotics* module (M2) at **SeaTech / Université de Toulon**, supervised by V. Hugel.

## 📝 Project Overview

A bird leg has four actuated joints (hip roll, inclined hip, knee, inclined ankle) but only three foot coordinates to control, so the leg is **redundant**. Starting from 3D positions of the toe, foot, ankle, knee and hip measured on a real bird over one walking cycle, the project:

1. **Controls the leg** with a pseudo-inverse of the foot Jacobian plus a null-space term that keeps the joint angles close to the rest pose. The foot follows the measured trajectory with an error below 0.07 mm.
2. **Shows what the null-space term does:** without it the joint angles drift by up to 15° at the end of the cycle, with it the motion is periodic.
3. **Optimises the orientation of two joint axes** (second hip joint and ankle joint, 4 angles in total) with `scipy.optimize.minimize` (Nelder-Mead, 4 starting points) so that the knee and ankle of the model get closer to the measured ones.

## 📊 Main Results

| Axis angles (ψh, ηh, ψa, ηa) | Knee error (RMS) | Ankle error (RMS) | Cost |
|---|---|---|---|
| Straight axes (90°, 90°, 90°, 90°) | 8.0 mm | 5.6 mm | 13.6 mm |
| Angles given in the assignment (116°, 55°, -93°, 67°) | 5.9 mm | 5.1 mm | 11.1 mm |
| **Optimised (137.9°, 69.7°, -70.3°, 66.2°)** | 5.9 mm | **3.6 mm** | **9.5 mm** |

* The cost is the sum of the knee and ankle RMS errors.
* The ankle error drops by 30 %, the knee error does not change: the model uses rigid segments while the measured segment lengths vary by 5 to 11 % over the cycle.
* Axes `(ψ, η)` and `(ψ + 180°, 180° - η)` are the same line with opposite direction: they give the same cost, and the optimiser reaches both.

## 🗂️ Repository Structure

* 📄 **`model.py`** : Leg model (Denavit-Hartenberg parameters, direct geometric model, Jacobians of the knee, ankle and foot). Provided by the teacher.
* 📄 **`myleg.py`** : Inverse kinematics loop (pseudo-inverse + null-space term) and plots of the trajectories and joint angles.
* 📄 **`optimisation.py`** : Same control loop written as a function, cost function, multi-start optimisation, and generation of all the report figures.
* 📁 **`fich-from-data-scilab/`** : Measured trajectories (`q12`, `mbv`, `fsb` files). Only `q12` is used in the report.
* 📁 **`figures/`** : Figures generated by `optimisation.py`.
* 📄 **`Report ** : Final report (PDF, in French).

## 🚀 How to Run

```bash
pip install numpy scipy matplotlib openpyxl
python myleg.py          # inverse kinematics with the assignment angles
python optimisation.py   # optimisation + figures (about 40 s)
```

Run the scripts from the repository root: the data file is read with a relative path.
